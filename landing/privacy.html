Политика конфиденциальности

Приложение «GroupFund» — последнее обновление: 23.09.2026

1. Какие данные обрабатывает приложение

Приложение работает как надстройка над Google Таблицами: с согласия пользователя оно создаёт и редактирует электронные таблицы Google на Google Диске владельца группы и предоставляет по ним доступ только по явному приглашению.

Приложение хранит на устройстве пользователя минимум данных: локальный список групп (идентификатор таблицы, название, дата последней синхронизации) и, пока не отменено, выбранный для входа аккаунт Google.

2. Куда данные не передаются

Приложение не передаёт, не продаёт и не предоставляет персональные данные третьим лицам. Все данные остаются в аккаунтах Google самих пользователей и доступны только участникам соответствующих групп через механизмы Google.

3. Разрешения Google

Для работы приложение запрашивает доступ к Google Таблицам и Диску выбранного аккаунта исключительно в объёме, необходимом для создания и обновления таблиц группы (скоупы Google Sheets API). Пользователь может отозвать этот доступ в любой момент в настройках своего аккаунта Google.

4. Уведомления

Приложение может показывать напоминания (например, о днях рождения), обрабатываемые полностью на устройстве. Подписки на push-уведомления не используются — напоминания не покидают устройство.

5. Удаление данных

Чтобы удалить данные приложения: удалите группу из списка в приложении или заблокируйте приложению доступ в настройках Google (myaccount.google.com → «Ваши подключения к сторонним приложениям»). Таблицы на Диске удаляются пользователем самостоятельно.
